## 尚待补齐的三项

1. **声压标定**：用标准声级计在 1 m 处给 60/70/80 dB(A) 三个点，拟合偏移量与斜率，
   把 `spl_db` 从相对值变成可报告的 dB(A)。
2. **方位精度**：转台每 15°一个点、每个点 30 次，统计平均角误差与 90 % 分位误差。
   注意用**近场拍手**做激励：白噪声/环境噪声是扩散场，各对时延本身就是随机的，只有直达声占主导时 TDOA 才有意义。实测孔径比 A/A标称 会直接给出四麦的真实间距（A = D·fs/c），可据此把 `D_MIC` 改成实测值；角度只取决于时延比值，与间距标称值无关。
3. **冷启动**：QSPI 固化镜像的 ID 读回异常未定位，当前交付以 JTAG 下载位流为准，
   报告与 README 都按这个前提写。

前两项不需要改 RTL，只加测量；第三项要先查 QSPI 跳线与 flash 型号匹配。
